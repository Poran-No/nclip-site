macOS Video Analysis Tool

動画解析を、
もっとシンプルに。

N Clipは、動画素材のカメラ・レンズ・カラー・動画・音声情報を すばやく確認できるmacOS向け解析ツールです。 編集前の素材確認を、ひとつの画面で効率化します。

N Clipについて サポートを見る
Features

編集前に必要な情報を、ひと目で。

動画素材を読み込むだけで、編集・カラー調整・素材管理に役立つ情報を整理して表示します。

📷

カメラ情報

カメラ名、メーカー、レンズ情報など、素材に記録された撮影情報を確認できます。

🎨

カラー情報

Gamma、Gamut、Matrix、Rangeなど、カラーマネジメントに必要な情報を確認できます。

🎞️

動画情報

解像度、フレームレート、コーデック、ビットレート、動画時間などを一覧表示します。

🔊

音声情報

Sample Rate、Channels、Bit Depth、Audio Codecなどを確認できます。

⚖️

素材比較

複数素材の解像度、FPS、Gamma、Gamutなどの違いを比較し、編集前の確認に役立てます。

📄

CSV書き出し

解析した素材情報や編集メモをCSV形式で保存し、素材管理や表計算ソフトで活用できます。

How to use

使い方は、3ステップ。

1

動画を追加

MP4、MOV、M4V形式の動画素材を選択、またはドラッグ＆ドロップします。

2

解析する

「選択中の素材を解析」を押すと、動画に記録された各種メタデータを解析します。

3

確認・書き出し

結果を確認し、必要に応じて素材比較やCSV書き出しを利用します。

FAQ

よくある質問

無料版では何本まで解析できますか？

無料版では、1回につき最大3本まで動画素材を解析できます。

Pro版では何ができますか？

Pro版では、動画素材の無制限解析とCSV書き出し機能をご利用いただけます。

Pro版はサブスクリプションですか？

いいえ。N Clip Proは買い切り形式で、一度購入すると継続して利用できます。

動画は外部サーバーにアップロードされますか？

N Clipは動画素材の解析をMac上で行う設計です。動画ファイルそのものをサポートページへ送信することはありません。

Privacy

プライバシーについて

N Clipは、動画素材の解析を目的としたmacOSアプリです。

N Clipは、アプリの主要な動画解析機能において、ユーザーが選択した動画ファイルを処理します。 ユーザーの動画素材を本Webサイトへアップロードすることはありません。

アプリ内課金はAppleのStoreKitおよびApp Storeを通じて処理されます。 開発者がユーザーのクレジットカード情報を直接取得することはありません。

本方針は、アプリの機能追加や法令・サービス仕様の変更に応じて更新される場合があります。
